# Cine4K 在线播放器

这是一个 Android 在线视频播放器。用户粘贴自己有权访问的视频直链即可播放，支持 Media3 ExoPlayer 可处理的 MP4、HLS（m3u8）和 DASH（mpd）等格式。

## 构建
GitHub Actions 会在推送到 main 后自动构建 Debug APK。也可在 Actions 页面手动运行 Android APK workflow。

## 下载
进入 Actions → 最新的 Android APK 构建 → Artifacts → 下载 `Cine4K-Player-APK`，解压得到 `app-debug.apk`。

## 当前范围
本项目目前提供播放器和视频直链播放能力，不包含电影资源库、第三方影视站点抓取、账号登录或付费内容解锁。请仅播放你拥有或获准访问的内容。
